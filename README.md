Taller 3 por Dante Pizarro y Antonio Arancibia, este proyecto consiste en un programa que a traves de un menu administrador y analista, gestionar distintos
magos y hechizos, se pueden agregar, eliminar,  modificar tanto magos como hechizos, y en el menu analista, se mostraran los magos y hechizos con mayores 
puntajes, ademas de la lista completa de magos o hechizos existe.

Este proyecto se ordeno segun la arquitectura de POO, separando la logica del dominio en dos paquetes distintos. En dominio se encontraran la clase mago, hechizo,
junto con los 4 clases de elementos que la heredan, ademas de las clases Visitor, que se implementaron para el calculo de puntajes. Por otro lado en la clase
Logica se encuentra App, la interfaz Sistema y la clase que lo implementa, SystemImpl.
